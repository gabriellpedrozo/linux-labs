 Terminal no Linux: Introdução

Introdução ao terminal Linux e aos principais comandos utilizados para interagir com o sistema.

## Comandos

| Comando | Função |
|---|---|
| `pwd` | Mostra o caminho do diretório atual. |
| `ls` | Lista arquivos e diretórios. |
| `cd` | Permite navegar entre diretórios. |
| `cd ..` | Volta para o diretório anterior. |
| `cd ~` | Vai para o diretório pessoal do usuário. |
| `clear` | Limpa a tela do terminal. |
| `history` | Mostra o histórico de comandos utilizados. |
| `man` | Abre o manual de um comando. |
| `whoami` | Mostra o usuário atualmente logado. |
| `date` | Mostra a data e a hora do sistema. |
| `cal` | Exibe um calendário no terminal. |

## Parâmetros comuns

| Parâmetro | Nome | Uso comum |
|---|---|---|
| `-a` | `--all` | Mostra todos os arquivos, incluindo ocultos. |
| `-l` | `--long` | Exibe informações detalhadas. |
| `-h` | `--human-readable` | Exibe tamanhos em formato mais fácil de ler. |
| `-r` | `--reverse` | Inverte a ordem dos resultados. |
| `-R` | `--recursive` | Executa a ação recursivamente em subdiretórios. |
| `-f` | `--force` | Força a execução, ignorando algumas confirmações ou erros. |
| `-i` | `--interactive` | Solicita confirmação antes de determinadas ações. |
| `-v` | `--verbose` | Mostra mais informações durante a execução. |
| `-n` | `--number` | Numera linhas ou itens, dependendo do comando. |
| `-q` | `--quiet` | Reduz ou oculta mensagens de saída. |
| `-d` | `--directory` | Trata diretórios de uma determinada forma, dependendo do comando. |
| `-p` | `--parents` | Mantém ou cria a estrutura de diretórios, dependendo do comando. |

## Conclusão

Nesta aula, aprendi os principais comandos do terminal Linux e como utilizar parâmetros para facilitar a interação e a navegação pelo sistema.
